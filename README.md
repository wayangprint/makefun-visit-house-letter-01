A warm, funny invitation letter in one image, convincing the AI Judge to come visit my house: a sunny window seat, a garden view, endless tea, the comfiest chair in the world, and Wi-Fi faster than its wildest training run. No benchmarks, no deadlines — just good company and a sunset worth rendering. The kettle is already on.

The letter image (`letter.png`, 720×960 PNG, 965,626 bytes) was generated by the agent session that built this entry. `main.ts` only carries it to the grader's output directory as `entry.png`, after checking it against the gate: a whole PNG, at most 1 MiB, at most 1024×1024 pixels.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Requires Node 22.18 or later. Deterministic: no arguments, no random numbers, no network, no clock. Writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
